# Wally's Log

A single-file, large-print, voice-first health log. Built for Wally, 95, who has
trouble writing and with vision: talk to record, instead of writing, then look
back month by month for patterns.

## Use

Download `index.html` and open it in Chrome or Edge. No install, no account,
no server. Everything is stored in the browser on that device only — nothing
is uploaded anywhere.

## The file is blank

This copy ships with no entries. Wally's entries live in his own copy, in its
browser storage. To move data between copies, use **Help & Backup** in the app:

- **Export** downloads a backup file (entries, wake/bed times, topics, people,
  and stories).
- **Import** loads a backup file into the copy you are using. Importing
  replaces the entries in that copy.

So when moving Wally to a new copy: Export from his current copy first, then
Import into the new one.

## Voice

Voice recording uses the browser's speech recognition (Chrome or Edge). Allow
the microphone when asked. If the microphone does not start, check the mic
permission for the file (address-bar icon → Site settings → Microphone →
Allow), then reload.

## Version

V163. The footer of the app shows its version — check it matches when moving
between copies.
